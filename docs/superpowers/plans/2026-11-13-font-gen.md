# font-gen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `font-gen` package that turns a reviewed Contract Y glyph store into an `.otf` (optionally `.ttf`) whose ligatures, positional forms and 7-state variant cycling fire under default-on OpenType features, plus a QA report and a HarfBuzz-shaped proof sheet, with a post-build self-check so a broken font is never written.

**Architecture:** Four small `hwfont-schema` precursors (the executable em-v1 convention `emspace.py`, `GlyphStore.load_raster`, `StrokePoint.width`) come first. Then a new hatchling package `packages/font-gen` whose modules form a pure pipeline `load → select → (nib, centerline, outline | autotrace) → metrics → features → build → qa → proof`, with I/O confined to `load.py`, `run.py` and the writers; `synth.py` ships in the package as the deterministic fixture generator and reference em-v1 implementation. Feature code uses per-tier shared ligature lookups plus one lookup per position-restricted ligature, inner-lookup positional substitution (`POS`/`TO_*`) and a glyph-identity ring counter (`STEPk`/`CYCLE`) with transparent-glyph skipping.

**Tech Stack:** Python 3.12+ (repo venv is 3.14), pydantic v2 (`hwfont-schema`), fontTools 4.68 (`FontBuilder`, feaLib, pens, `agl`, `timeTools`), skia-pathops 0.9, numpy, Pillow, uharfbuzz 0.57 (hard dependency), optional scikit-image (raster fallback) and cairosvg (PNG proof), pytest.

**Spec:** [docs/superpowers/specs/2026-11-13-font-gen-design.md](../specs/2026-11-13-font-gen-design.md)

## Review Focus

Five input classes the spec implies but its own test list never exercises; each is pinned by a test added to the owning task below.

1. **Ring whose only good sample is raster-only while a marginal stroke sample exists** (Task 8): source orders before quality (spec §7.6: a raster-fallback glyph "is never slot 0 of a ring when a stroke-sourced sample exists"), so the marginal stroke sample is slot 0, the raster-only good is `.alt1`, and `marginal_used` fires — pinned so nobody "fixes" it the other way silently.
2. **A sample whose every contour dedupes to one point** (Tasks 16, 18): empty outline must survive `hmtx`, charstring, reload (Task 16) and `self_check` (`BoundsPen` returns `None`, Task 18) without a crash or a finding.
3. **Store where every ring is a singleton and no positional ring exists** (Tasks 14, 18): `STEP*`, `CYCLE`, `TO_*`, `POS` are all empty, so `calt` must be omitted entirely and the self-check must not demand it.
4. **Ligature whose component single has no glyph in the font** (Tasks 8, 14): the ligature glyph is emitted with no rule and `ligature_component_missing` (warn); feaLib must still compile.
5. **Proof row containing a character outside the cmap** (Task 19): HarfBuzz yields `.notdef`; the renderer must draw it (one `<path>` per shaped glyph) rather than raise.

import struct
import zlib

from hwfont_schema.emspace import png_size, raster_em_to_px, raster_px_to_em


def _png(width, height):
    def chunk(tag, body):
        return struct.pack(">I", len(body)) + tag + body + struct.pack(">I", zlib.crc32(tag + body) & 0xFFFFFFFF)
    ihdr = struct.pack(">IIBBBBB", width, height, 8, 0, 0, 0, 0)
    raw = b"".join(b"\x00" + b"\xff" * width for _ in range(height))
    return b"\x89PNG\r\n\x1a\n" + chunk(b"IHDR", ihdr) + chunk(b"IDAT", zlib.compress(raw)) + chunk(b"IEND", b"")

    assert png_size(_png(154, 154)) == (154, 154)

def _flatten_recording(value, n=16):
    """Dense polylines (one per contour) of a RecordingPen value holding lines, quads (TrueType-style) and cubics."""
    polys, cur = [], None
    for op, args in value:
        if op == "moveTo":
            cur = np.array(args[0], float); polys.append([cur])
        elif op == "lineTo":
            cur = np.array(args[0], float); polys[-1].append(cur)
        elif op == "qCurveTo":
            for q, p in decomposeQuadraticSegment(args):
                q, p = np.array(q, float), np.array(p, float)
                for t in np.linspace(0, 1, n + 1)[1:]:
                    polys[-1].append((1 - t) ** 2 * cur + 2 * (1 - t) * t * q + t * t * p)
                cur = p
        elif op == "curveTo":

            for t in np.linspace(0, 1, n + 1)[1:]:
                polys[-1].append((1 - t) ** 3 * cur + 3 * (1 - t) ** 2 * t * c1 + 3 * (1 - t) * t * t * c2 + t ** 3 * p)
            cur = p
    return [np.array(p + [p[0]]) for p in polys]


def _max_distance(points, polylines):
    """Largest distance from any of `points` to the nearest segment of any polyline."""
    best = np.full(len(points), np.inf)
    for poly in polylines:
        a, b = poly[:-1], poly[1:]
        ab = b - a
        t = ((points[:, None, :] - a[None]) * ab[None]).sum(-1) / np.maximum((ab * ab).sum(-1), 1e-12)[None]
        proj = a[None] + np.clip(t, 0.0, 1.0)[..., None] * ab[None]
        best = np.minimum(best, np.linalg.norm(points[:, None, :] - proj, axis=-1).min(axis=1))
    return float(best.max())

def fit_outline(union_path, max_err=QU2CU_ERR):
    if not list(union_path.contours) or path_area(union_path) == 0.0:
        return Outline.empty(), "empty"
    candidate = quads_to_outline(union_path, max_err)
    if is_intersection_free(candidate) and drift_ok(candidate, union_path):
        return candidate, "qu2cu"
    candidate = elevated_outline(union_path)
    if is_intersection_free(candidate) and drift_ok(candidate, union_path):
        return candidate, "elevation"
    for _ in range(FIXED_POINT_ROUNDS):
        q = outline_to_path(candidate)
        q.simplify(fix_winding=True, keep_starting_points=True, clockwise=False)
        rec = RecordingPen(); q.draw(rec)
        candidate = Outline.from_recording(rec.value)
        if is_intersection_free(candidate) and drift_ok(candidate, union_path):
            return candidate, "fixed_point"
    return candidate, "unstable"
